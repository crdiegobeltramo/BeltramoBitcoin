La tesis del libro

No es un manual de prompts.
Es un sistema operativo de inversión.

Datos → Investigación → Análisis → Valuación → Riesgo → Construcción de cartera → Monitoreo → Decisión → Seguimiento.

Ese es el circuito completo de un Portfolio Manager. Este libro enseña a poner a Claude a trabajar en cada eslabón de esa cadena — como analista junior, como analista senior y como asistente de research — sin nunca delegarle la decisión final de asignación de capital.

Cada capítulo sigue una estructura fija: objetivo, concepto financiero, aplicación profesional, cómo usar Claude, skill relevante (con su nivel de procedencia verificado), un prompt reutilizable y sus errores frecuentes. Todo organizado bajo un framework propio — el PM-AI Framework — que atraviesa las diecinueve partes del libro.

El resultado no es una colección de trucos. Es la arquitectura completa de un Portfolio Manager aumentado por inteligencia artificial, con el humano siempre como última instancia de aprobación.

Por qué es distinto

Cinco decisiones editoriales que no vas a encontrar en otro libro de IA financiera

01

Honestidad sobre las skills

El libro distingue explícitamente qué es oficial de Anthropic, qué es de un partner, qué es de la comunidad y qué es una propuesta original — en vez de inventar que una skill existe.

02

Metodología propia: el PM-AI Framework

Perception, Market, Analysis, Intelligence, Risk, Expected return, Allocation, Scenario, Optimization, Narrative — un hilo conductor transversal a las diecinueve partes.

03

La cobertura cripto más profunda

31 capítulos dedicados: MVRV, NVT, SOPR, exchange flows, minería, Lightning Network y Bitcoin tratado explícitamente como activo macro — no como nota al pie.

04

Mirada Argentina y LatAm real

Riesgo país, ONs, ARS/USD, agro como commodity estratégico — integrado donde corresponde, sin perder el alcance institucional global del resto del libro.

05

De la teoría al sistema operativo

Arquitectura multi-agente completa, especificación de una skill propia (portfolio-manager-ai) y una biblioteca de 100 prompts listos para usar desde el día uno.

06

Human-in-the-loop, siempre

Ningún workflow del libro está diseñado para ejecutar una operación de forma autónoma. La responsabilidad de la decisión final es, en todos los casos, del Portfolio Manager humano.
