¿Qué es un servidor MCP?

MCP (Model Context Protocol) es el estándar abierto que le permite a un asistente de IA usar herramientas externas reales durante la conversación, en lugar de responder solo con lo que sabe de memoria.

🤖 Tu asistente
(Claude / ChatGPT / Gemini / Grok)
→
🔌 Este servidor MCP
→
📈 Tu cuenta de IOL Inversiones

Qué puede hacer tu asistente con esto

Seis capacidades de análisis de inversiones, disponibles como herramientas que tu IA puede invocar directamente.

💼

Portfolio Manager

Trae tu cartera actual, saldos, cotizaciones y series históricas directo desde IOL.

📐

Optimización de Markowitz

Calcula la cartera de máximo Sharpe o de mínima varianza para un retorno objetivo.

⚡

Stress Testing

Simulá shocks porcentuales (una caída, una devaluación) y mirá el impacto en tu cartera.

🔄

Portfolio What If

Simulá rebalancear a nuevos pesos objetivo sin mover un peso real todavía.

📝

Thesis Tracker

Registrá y consultá tus tesis de inversión por activo, con precio objetivo y horizonte.

🧭

Resumen tipo copiloto

Composición, concentración por activo y alertas automáticas de tu cartera.

Descargá el servidor

Un único archivo .zip con el código Python, listo para instalar.

⬇ Descargar iol-investment-mcp.zip

Requiere Python 3.9+ y una cuenta activa en IOL Inversiones con API habilitada.

Cómo instalarlo

Elegí tu asistente. Cada uno conecta MCP servers de forma distinta.

Claude Desktop servidor local

  1. Descomprimí el .zip y, adentro de la carpeta, instalá dependencias: pip install -r requirements.txt
  2. Copiá .env.example a .env y completá tu usuario y clave de IOL.
  3. Abrí la configuración de Claude Desktop: Settings → Developer → Edit Config (abre claude_desktop_config.json).
  4. Agregá esta entrada, con las rutas completas a tu instalación:
{
  "mcpServers": {
    "ia-para-el-inversor": {
      "command": "/ruta/completa/.venv/bin/python",
      "args": ["/ruta/completa/iol-investment-mcp/server.py"],
      "env": {
        "IOL_USERNAME": "tu_usuario_iol",
        "IOL_PASSWORD": "tu_password_iol"
      }
    }
  }
}
  1. Reiniciá Claude Desktop. Deberías ver el conector activo y sus herramientas disponibles en el chat.

Gemini CLI / Antigravity servidor local

  1. Instalá dependencias igual que en el paso 1 de Claude, y configurá tu .env.
  2. Editá ~/.gemini/settings.json (o el equivalente de Antigravity) y agregá el servidor en mcpServers:
{
  "mcpServers": {
    "ia-para-el-inversor": {
      "command": "/ruta/completa/.venv/bin/python",
      "args": ["/ruta/completa/iol-investment-mcp/server.py"],
      "env": {
        "IOL_USERNAME": "tu_usuario_iol",
        "IOL_PASSWORD": "tu_password_iol"
      }
    }
  }
}

Google migró Gemini CLI gratuito a Antigravity durante 2026; el bloque de configuración de MCP es prácticamente el mismo en ambos. Revisá la documentación oficial vigente si la ruta del archivo cambió.

Grok CLI / Grok Build servidor local

  1. Instalá dependencias y configurá tu .env como en los casos anteriores.
  2. Desde la terminal, registrá el servidor:
grok mcp add ia-para-el-inversor --scope user \
  -- /ruta/completa/.venv/bin/python /ruta/completa/iol-investment-mcp/server.py

Esto aplica a Grok CLI / Grok Build, el agente de terminal de xAI. El Grok conversacional dentro de X no ofrece hoy una forma pública de conectar servidores MCP propios.

ChatGPT requiere servidor remoto

ChatGPT solo se conecta a servidores MCP remotos (HTTPS), no ejecuta servidores locales como este directamente. Para usarlo ahí primero hay que desplegarlo en un hosting propio (por ejemplo un VPS o servicio cloud) detrás de HTTPS.

  1. Desplegá server.py en un servidor con HTTPS accesible públicamente.
  2. En ChatGPT: Settings → Connectors → Advanced → activar Developer mode (disponible en planes Plus/Pro/Team/Enterprise).
  3. Agregá tu conector con la URL pública de tu servidor.
