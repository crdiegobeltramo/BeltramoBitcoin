El eje del libro

Un sistema operativo de inversión, no una colección de prompts

Cada parte del libro alimenta un ciclo completo: investigar, analizar, valuar, construir la cartera, medir sus riesgos, monitorear su evolución, rebalancear cuando corresponde y aprender de cada decisión antes de volver a investigar.

Human-in-the-loop en cada paso: Claude investiga, calcula y cuestiona la tesis — el Portfolio Manager humano decide y asume la responsabilidad. Ningún agente del libro tiene mandato para ejecutar una operación por su cuenta.

Del libro al sistema

portfolio-manager-ai, la Skill que construís mientras leés

El libro no se queda en la teoría: cada parte deja una pieza lista para convertirse en una Agent Skill de Claude, con instrucciones, subskills y plantillas propias.

  • SKILL.md raíz con el mandato, el universo elegible y las restricciones de tu propio proceso de inversión.
  • Once subskills — una por clase de activo y por función, de equity research a portfolio-impact-test.
  • Templates listos — Investment Thesis Card, Investment Committee Memo, Decision Journal.
  • Compatible con Claude.ai, Claude Code y la API — se construye una vez, funciona en cualquier entorno.
